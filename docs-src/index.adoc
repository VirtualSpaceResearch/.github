This documentation is authored in AsciiDoc, with diagrams maintained as PlantUML source.
Generated HTML is published from the tracked `docs/` directory.

== Documentation system

The source files in `docs-src/` are the source of truth. Do not edit generated files in
`docs/` directly; rebuild them from the sources instead.

== Generation flow

[plantuml, generation-flow, svg]
....
@startuml
rectangle "AsciiDoc\n docs-src/*.adoc" as adoc
rectangle "PlantUML\n docs-src/diagrams/*.puml" as puml
rectangle "Asciidoctor\n + diagram extension" as build
folder "Generated HTML\n docs/" as output

adoc --> build
puml --> build
build --> output
@enduml
....
